# Examination typography assets

Be Vietnam Pro weights400/500/600/700, Latin/Latin Extended/Vietnamese WOFF2
subsets, downloaded independently from the official Google Fonts service on
2026-10-20. No VN Exams assets or authenticated cache files were copied.

The [SIL Open Font License](OFL.md) and upstream copyright accompany these
unmodified font files. [Source URLs, sizes and SHA-256](manifest.json) pin the
bytes used. Browser requests stay local through `/fonts.css` and an exact
static-file allowlist; no runtime Google Fonts request is made.

Only the exam workspace selects this font; existing product/staff fonts remain
unchanged. The public license endpoint is `/fonts/OFL.txt`.
