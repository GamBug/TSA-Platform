# Agent onboarding

Read only the material needed for the assigned task. Historical records are preserved in [the dated archive](../archive/2026-11-08/) and should be opened only when the task requires history.

## Deterministic sequence

1. Read [AGENTS.md](../../AGENTS.md) and [current project state](PROJECT_STATE.md).
2. Read the assigned task card only: confirm its dependencies, owner, scope, deliverables, and checks.
3. Read only task-specific specifications and decision evidence linked by that card. Open archived records on demand.
4. Inspect `git status --short`, branch, and HEAD before editing; preserve unrelated work.
5. Run the checks required by the assigned card and record actual commands and results.

## Before editing

State the assigned task, accountable implementer, starting Git state, approved decisions versus open questions, reserved files, frozen contracts, acceptance checks, and known issues. If a fact is missing and affects the authorized scope, ask the owner before changing it.

## At handoff

Update only coordinated shared records. Record repeatable verification evidence, tests not run, review status, remaining acceptance gaps, ownership transfer, and the next authorized action. Do not treat historical proposals or agent recommendations as approval.
